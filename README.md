### 🧭 What I'm about

I don't start from *"what should I build?"* — I start from three questions:

> 1. *What's the real problem here?*
> 2. *Can this be made more meaningful?*
> 3. *Can this be made more alive, beautiful, inventive?*

Other people build websites — I build **experiences**. I care about the part most tools skip: the **soul** of a thing. Product thinking, system design, and aesthetics in one head — heavy on AI-assisted, flow-based building.
